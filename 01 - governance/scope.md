# Information Security Management System (ISMS) Scope

## 1. Context and Organization
Northbridge Health Ltd operates a cloud-native patient scheduling platform for healthcare providers across the United Kingdom[cite: 1]. 

## 2. ISMS Boundaries
The scope of the Information Security Management System covers:
* **Physical Boundary:** Remote workforce across the UK and headquarters operations.
* **Technical Boundary:** All AWS cloud infrastructure hosting the Northbridge patient scheduling SaaS, database repositories, API endpoints, and the ML triage model[cite: 1].
* **Data Boundary:** Processing, storage, and transmission of patient scheduling data and PII[cite: 1].

## 3. Exclusions
* Third-party healthcare provider internal systems (out of management control).

## 4. Regulatory & Compliance Drivers
* **ISO/IEC 27001:2022** Information Security Standard[cite: 1]
* **UK Data Protection Act 2018 / UK GDPR**[cite: 1]
* **NHS Data Security and Protection Toolkit (DSPT)** guidelines
